# 使用简易代理

固件内置「简易代理」，支持一次性粘贴多个节点，自动识别 `ss://` / `vmess://` / `vless://` / `trojan://`。

## 入口

后台 → **服务 → Shadowsocks-libev → 简易代理**

## 步骤

1. **添加节点**：把节点链接粘到文本框（每行一个，可一次贴多个），点「添加节点」。`vmess://` 会自动解码。
2. **选用节点**：在节点列表里点目标节点的「选用」。
3. **启用代理**：勾选「启用代理」，访问模式选「绕过大陆」或「全局代理」。
4. **保存并应用**：点按钮，稍等几秒看状态。

## SS 与 VMess/VLESS/Trojan 的区别

| 协议 | 后端 | 特点 |
| :--- | :--- | :--- |
| SS | 内置 `ss-redir` | 最快，K2P 首选 |
| VMess / VLESS / Trojan | 运行时下载的 Xray | 首次下载约 10MB；重启后需重新下载 |

- **SS** 走内置官方 shadowsocks-libev，K2P 上速度最快（极限约 70Mbps）。
- **VMess/VLESS/Trojan** 点「保存并应用」时会从国内镜像下载 Xray 到内存，用 `geosite:cn` 分流。⚠️ **每次重启路由器都要重新下载**（约 10MB，1-2 分钟），开机后会自动恢复，首次启动请耐心等待。

## 下载源

Xray 内核默认从公共加速镜像下载。若状态里提示下载失败，在页面底部「下载源」换成其它 `gh` 加速前缀后重试。

## 测试延迟

点「测试延迟」会对每个节点做 TCP 连通性测速，用于挑选节点（不影响代理本身）。

## 关代理

取消「启用代理」，再点一次「保存并应用」。
